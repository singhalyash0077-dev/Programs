# C Programming: 132 Solved Questions

A GitHub-ready collection of independent C solutions for all 132 questions in the supplied practice sheet.

## Compile

Each file is standalone:
```bash
gcc Q001.c -o q1 -lm
./q1
```

The `-lm` flag is only required by solutions using `<math.h>`.
